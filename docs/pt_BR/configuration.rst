Configuração
============

1. No Telegram, crie o bot com o @BotFather e copie o token.
2. *Administração do site > Geral > Mensagens > Bot do Telegram*: cole o token e salve.
3. Na mesma página, siga o link *Envie uma mensagem de teste* (ou *Administração do site > Geral > Mensagens >
   Enviar mensagem de teste ao Telegram*). Informe o id de um chat e envie: a página mostra se o Telegram
   entregou a mensagem ou o erro que ele devolveu, sem o token. O bot precisa estar no grupo, ou a pessoa precisa
   ter iniciado uma conversa com ele.
4. *Administração do site > Geral > Mensagens > Configurações de notificação*: habilite o "Bot do Telegram" nos tipos
   de notificação que devem ir para o Telegram (e trave, se o usuário não puder mudar).
