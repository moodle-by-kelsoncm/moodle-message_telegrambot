Configuration
=============

1. In Telegram, create the bot with @BotFather and copy the token.
2. *Site administration > General > Messaging > Telegram bot*: paste the token and save.
3. On the same page, follow the link *Send a test message* (or *Site administration > General > Messaging >
   Send a Telegram test message*). Type the id of a chat and send: the page shows whether Telegram delivered
   the message, or the error it returned, without the token. The bot must be in the group, or the person must have
   started a chat with it.
4. *Site administration > General > Messaging > Notification settings*: enable "Telegram bot" for the notification
   types that should go to Telegram (and lock them if users must not change it).
